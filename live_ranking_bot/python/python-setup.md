**This document helps you install Python for the sample**

# Install Python

## Windows

1. Visit the Python downloads page: [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. Download a recent Windows installer.
3. During installation, enable `Add Python to PATH`.
4. Verify with:

```bat
python --version
pip --version
```

## macOS

Install with Homebrew:

```bash
brew install python
python3 --version
```

## Linux

On Debian/Ubuntu:

```bash
sudo apt update
sudo apt install python3 python3-pip
python3 --version
pip3 --version
```
